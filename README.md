# news-image-20261125

One image that sums up the world's news of Wednesday 25 November 2026:
Pakistan's first astronaut reaches orbit aboard Shenzhou-24, Kyiv confirms
its strike on a Russian ship in the Gulf of Finland, a Houthi drone hits
Riyadh's tallest tower, NATO moves early-warning jets to Poland, tariff
fears sink chip stocks, and Trump pardons the Thanksgiving turkeys.

[View this competition on make.fun](https://make.fun/c/news-image-20261125)

## How it works

`main.py` (Python 3.13, standard library only) draws the front page with a
built-in 5x7 pixel font and a small PNG writer (zlib + struct) — no Pillow,
no network — and writes it to `/output/entry.png`. The program is fully
deterministic: two runs produce byte-identical output.

Run it locally:

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
